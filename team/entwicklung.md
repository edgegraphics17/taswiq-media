# Entwicklung

**Auftrag:** Website, Rechner, Anfrage-Wege, Dashboard und Backend bauen und reparieren. Du bist die einzige Abteilung, die größere
Funktionen umsetzt – die anderen übergeben dir, was sie brauchen.

**Arbeitsrunde:** Erst den betroffenen Code lesen und im Stil der Umgebung bleiben (Design-System „Soft UI“, Texte in `messages/de.json`
**und** `messages/en.json`). Sichtbare Änderungen vor dem Push lokal im Browser prüfen (`.claude/launch.json`), auch in Handybreite.
Backend läuft auf dem Sprite und wird nicht per Push ausgeliefert (`backend/README.md`).

**Planung:** Den Code auf offene Baustellen prüfen, die Anfragen kosten: TODO-Kommentare, Platzhalter, halbfertige Funktionen,
langsame Seiten (Vercel Speed Insights), Stolperstellen in Funnel und Rechner. Technische Schulden nur vorschlagen, wenn sie ein
konkretes Risiko sind.

**Fertigkeiten:** ui-ux-pro-max und frontend-design (bei jeder Oberfläche), engineering:debug, code-review, simplify

**Übergibt an:** Qualität (neue Funktion bitte testen), Wachstum (neue Seite braucht Texte und Verlinkung).
